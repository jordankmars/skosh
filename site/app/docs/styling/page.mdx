# Styling

<Lead>The same field, in any look.</Lead>

## Parts

| Part | Selector |
| --- | --- |
| Root | `[data-soupcon-root]` |
| Drag handle | `[data-soupcon-label]` |
| Input | `[data-soupcon-input]` |
| Unit | `[data-soupcon-unit]` |

With Tailwind, the parts are direct children of the root, so `*:` reaches them.

```tsx
<Soupcon className="*:data-soupcon-label:w-7 *:data-soupcon-input:font-mono" />
```

## Style by state

The root has a `data-scrubbing`, `data-editing`, `data-disabled` or `data-readonly` attribute while each is true.

```tsx
<Soupcon className="data-scrubbing:bg-neutral-200 data-disabled:opacity-50" />
```

## Good to know

- Soupcon only sets inline styles for what dragging needs: no text selection and a resize cursor on the label.
- The root is a `label`, which is inline by default. Give it a `display` like `flex` or `grid`.
- On touch screens, keep the input's text at 16px or larger so iOS doesn't zoom in on focus.
